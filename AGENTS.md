## Dreative frontend design-builder
For frontend design or redesign work, read `.codex/skills/dreative/SKILL.md` first. Build in the real application, inspect the rendered full page at desktop and mobile, correct visible failures, and run the project's deterministic checks. Substantial work is incomplete unless `dreative finalize --codex` succeeds against the current source and prints `DREATIVE_FINALIZED`. This marker certifies command success only, not visual quality. After any finalization failure, report the build as incomplete and list the blockers.
