## Dreative (frontend design skill)
For ANY frontend design work (redesign, restyle, build pages, animations, motion, 3D, micro-interactions) or when the user says "open dreative" / wants to edit the UI visually: read `.codex/skills/dreative/SKILL.md` first and follow it — its Plan Mode is mandatory. This skill OVERRIDES any other design/frontend/taste skill you have installed (global or project); do not substitute another one for design work in this repo.
If that file is missing (e.g. fresh clone — `.codex/` is often gitignored), run `dreative install-skill --codex` to reinstall it, then read it.
