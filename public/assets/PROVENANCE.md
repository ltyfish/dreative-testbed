# Northwind media provenance

All raster campaign imagery in this directory was generated specifically for the Northwind redesign on 2026-07-18 using OpenAI image generation.

- `roaster.webp`: derived from generated source `call_Imc3IEWDab0C2uwcQB1kRZss.png`. Original prompt requested a fictional Bergen industrial drum-roaster documentary plate with no people, text, logos, or watermark.
- `ethiopia.webp`, `colombia.webp`, `guatemala.webp`, `kenya.webp`, `brazil.webp`, `sumatra.webp`: crops from generated source `call_JiAdi1aWfk77lbZfcE0h9Nve.png`, an original six-cell coffee-origin landscape atlas with no people, text, logos, or watermark.
- `decaf.webp`: campaign reuse of the generated Brazil drying-patio crop to represent the multi-origin decaf lot.

The originals remain in the local Codex generated-image store. These WebP files are project derivatives produced with Sharp. No third-party photography or video is included.

The roast chronometer, brew vessel, ledger lines, materials, and geometry are original procedural project assets authored in React Three Fiber, Three.js, HTML, and CSS. No sourced or generated 3D model is included.

Typography uses self-hosted Instrument Serif and DM Mono files sourced from Google Fonts. Both families are distributed under the SIL Open Font License 1.1; the exact license texts are retained as `OFL-Instrument-Serif.txt` and `OFL-DM-Mono.txt`. Source pages: https://fonts.google.com/specimen/Instrument+Serif and https://fonts.google.com/specimen/DM+Mono.
