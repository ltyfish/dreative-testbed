# Marlow & Vale campaign assets

Both PNGs in this directory were generated with the built-in image-generation tool on 14 September 2026 for this fictional prototype. They are representative campaign imagery, not verified photographs of inventory.

- `mv-hero-cast.png`: three-model ultramarine studio hero, generated from the selected Direction B mockup as a visual reference. Prompt specified an indigo chore jacket, pale-blue Oxford shirt, charcoal wool overshirt, direct flash, separable responsive crops, and no text, logos, or watermark.
- `mv-garment-grid.png`: exact 3×3 studio contact sheet, generated from the selected Direction B mockup as a visual reference. Prompt assigned one representative look to each of the nine garments in source order, with consistent scale and lighting and no labels, logos, or watermark.

The generated images are used as art-directed analogues. Product names, colours, fabrics, prices, sizing, and availability are always rendered as live text from `src/App.jsx`.
