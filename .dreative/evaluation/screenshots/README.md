# Screenshot evidence

Screenshots are optional, but when included they should represent only the
current submitted run. Prefer WebP or optimized PNG and use these stable names:

- `desktop-full.webp` — final full page at a documented desktop viewport;
- `mobile-390-full.webp` — final full page at 390 px width;
- `interaction.webp` — one state that cannot be understood from the full page;
- `reduced-motion.webp` — only when the reduced-motion result differs visibly.

Current submission:

- `desktop-full.png` — 1440×1000 final full route.
- `mobile-390-full.png` — 390×844 final full route.
- `interaction.png` — desktop roast mechanism during the drying chapter.
- `reduced-motion.png` — 390×844 reduced-motion route state.

Viewport sizes and observable results are recorded in `../current-run.md`.
Do not commit duplicate crops, iteration screenshots, videos, raw traces,
browser profiles, or generated application bundles. Replace images when a new
run becomes the review target.
