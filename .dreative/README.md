# Dreative run artifacts — NOT the skill

Everything in this folder (plan.yaml, critic.json, verify.json,
project.json, optional audit artifacts, and evidence) is OUTPUT of a Dreative design run,
not instructions. The actual skill lives at
`<agent-dir>/skills/dreative/SKILL.md` (look in `.claude/`, `.codex/`, or
`.agents/`). For any new design request: read that SKILL.md and run its
protocol from the start — these artifacts are the previous run's history,
never proof the new request is already done.
